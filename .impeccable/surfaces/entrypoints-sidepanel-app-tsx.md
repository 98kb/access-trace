# Side panel

Mode: Operate. Scope: the Chrome side-panel application.

Audience: developers moving repeatedly from a concise finding to the live page element. Task: scan, triage by status and impact, locate, toggle overlay, rescan. Content and states are fixed by the implementation ticket. The UI must remain useful in a narrow panel and light or dark Chrome environments.

## Direction contract

THESIS: A compact inspection ledger where results, selection, and page location read as one continuous instrument; refuse dashboard tiles.

OWN-WORLD: Neutral ink surfaces, one violet action accent, amber review cues, square data rows, hairline rules, system UI type, monospace only for evidence.

STORY: Identify the page, run a local scan, narrow findings, select one, and see its exact live target.

FIRST VIEWPORT: Page identity and scan action lead; after scanning, a two-column count strip and sticky filters feed a single dense result ledger.

FORM: Brief-pinned restrained developer tool, shaped directly for a local extension (`brief-pinned`).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
